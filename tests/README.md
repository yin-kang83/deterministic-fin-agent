# tests/ · 跨模块断言

本目录放**跨模块**的测试（单个模块的自检留在 `src/*.py` 的 `_selftest()` 里，便于单文件运行）。

## 为什么这里也有测试

`src/` 的自检证明「每个模块自己成立」；本目录证明「模块之间接得上」——
尤其是不变量跨模块时（如「状态机写入链后，链仍可验」）。

## 一条纪律

**测试可以碰内部（`c._blocks[...]`），生产类不提供测试后门。**

原先 `Chain` 上有个 `tamper_for_test()` 方法，已删除：
它让伪装篡改成为**生产 API 的一部分**，任何人调一次就能改底稿，而这正是本模块要防的事。
测试要改内部，就直接碰内部——那是测试的事，不该由被测对象提供便利。
